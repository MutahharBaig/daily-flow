BUILD YOUR DAYFLOW APK (free, no coding)
1. Create a free account at github.com and make a NEW repository (any name, Public or Private).
2. On a computer, unzip this file. In the repository click "Add file > Upload files" and drag in EVERYTHING
   inside the unzipped folder (including the hidden ".github" folder). Click Commit.
3. Open the "Actions" tab. "Build APK" runs automatically (about 5-8 minutes). If not, open it and press "Run workflow".
4. When it shows a green tick, open the run and download "Dayflow-APK" (a zip containing app-debug.apk).
5. Send the APK to your phone, tap it, allow "Install unknown apps", install.
6. First launch: create PIN, allow Notifications, Physical activity, and "Alarms & reminders" when asked.
7. Phone Settings > Battery > Dayflow > set to "Unrestricted" so alarms are never delayed.
